Здравствуйте, в проекте пеализован функционал поиска значения по ключу на x86-64 assembly with nasm
В данном проекте реализовано:
  функции для работы с текстом, считыванием выводом информации через системные вызовы в unix подобных os,
  создание разделяемой библиотеки,
  поиск в файле строки-ключа по переданному значению и вывод в  stdout, обработка ошибок.
 Чтобы воспользоваться функционалом необходимо скопировать репозиторий, подставить подходящие вашей системе инструменты сборки в переменные в makefiles,
 заполнить файл words.inc вашими парами ключ-значение в соответствии с представленным форматом.
 
Программа с помощью макроса colon создаст структуру, на логическом уровне являющуюся связным списком, на этапе сборки. В которой метки являются указателями на узлы.
Поиск идет начиная с метки first_word, которую нельзя менять! (или, если измените, то измените в файле dict.asm тоже).
